# python-sales-data-analysis

#  Análise de Cancelamento de Clientes com Python (Situação no código)

Projeto de **Análise de Dados utilizando Python**, com o objetivo de identificar padrões de cancelamento de clientes em uma empresa e propor possíveis soluções para reduzir esse índice.

Este projeto foi desenvolvido como parte de um estudo prático de **Data Analysis**, utilizando ferramentas amplamente usadas no mercado.

---

#  Objetivo do Projeto: 

O objetivo principal foi analisar uma base de dados de clientes para:

- Identificar **o percentual de cancelamento**
- Descobrir **quais fatores influenciam no churn (cancelamento)**
- Encontrar **padrões comportamentais nos clientes**
- Propor **possíveis estratégias para reduzir cancelamentos**

Esse tipo de análise é muito utilizado em empresas para melhorar **retenção de clientes e tomada de decisão baseada em dados**.

---

# Conceitos Aplicados:

Durante o projeto foram aplicados conceitos importantes de análise de dados:

- Limpeza de dados
- Tratamento de valores inconsistentes
- Exploração de dados
- Análise estatística básica
- Visualização de dados
- Interpretação de resultados
